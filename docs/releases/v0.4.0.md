# v0.4.0 — Cartes unifiées et notifications plus lisibles (publiée)

## Changements

- Migration complète des cartes vers la configuration partagée `flowio/config`.
- Suppression des champs locaux `entity_prefix`, `mqtt_topic`, `tank_slots` et `runtime_slots` dans les démos, exemples, éditeurs et tests.
- Ajout de `device_slot` à la carte Piscine pour la télémétrie de l’équipement, sans réémission des slots internes.
- État de la pompe désinfectant conservé même si le type de traitement est absent ou indisponible ; les commandes restent désactivées tant que la cible n’est pas connue.
- Jauges et libellés accessibles corrigés, avec bornes firmware cohérentes.
- Noms anglais publiés par le firmware traduits dans les cartes françaises ; les renommages personnalisés distincts restent intacts.
- Notifications Android/iPhone plus aérées, une valeur par ligne, en conservant icônes, couleurs et pastilles.
- Même présentation du récapitulatif dans les notifications persistantes Live Activity / Live Update.
- Textes des notifications, actions, canaux, durées et alertes chargés depuis les fichiers de traduction selon la langue Home Assistant.
- CI renforcée : 171 tests unitaires, 139 tests Playwright et audit des dépendances de production.
- Synchronisation de la version du lockfile `cards/package-lock.json` à `1.0.0`.

## Migration

Retirer des cartes Lovelace existantes les anciens champs locaux :

- `entity_prefix`
- `mqtt_topic`
- `tank_slots`
- `runtime_slots`

Le préfixe, la racine MQTT et les slots proviennent désormais de l’intégration Flow.io. Les identifiants d’entités restent explicitement sélectionnables dans les cartes qui le nécessitent.
