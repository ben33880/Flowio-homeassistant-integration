# v0.4.1 — Tableau de bord moderne et options organisées

## Changements

- Nouvelle carte `custom:flowio-pool-dashboard-card`.
- Présentation moderne en trois colonnes : qualité de l’eau, équipements, traitement.
- Modes regroupés sur une bande dédiée et horaires/durées sur toute la largeur.
- Même configuration et mêmes fonctionnalités que `custom:flowio-pool-card` : commandes, confirmations, remplissage des cuves, injections, modes, horaires, télémétrie et diagnostic.
- `flowio-pool-card` reste disponible sans changement de type ni de comportement.
- Options de l’intégration réorganisées en trois écrans :
  1. contrôleur et slots ;
  2. téléphones et notifications ;
  3. équipements surveillés.
- Conservation des réglages existants entre les étapes de configuration.

## Utilisation

La nouvelle carte accepte la même configuration que la carte Piscine. Il suffit de changer le type :

```yaml
type: custom:flowio-pool-dashboard-card
title: Supervision
```

Tous les blocs `display`, `visuals` et `device_slot` restent compatibles.
