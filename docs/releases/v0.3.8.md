# v0.3.8 — Correction du blocage du sélecteur de cartes

## Corrections

- Correction de la boucle de rendu dans la grille de tuiles commune, notamment utilisée par Flow.io Modes : l’attente des réglages de l’installation et l’état d’erreur ne doivent plus redemander un rendu lorsque l’état est déjà nettoyé.
- Réinitialisation du chargement à la déconnexion de la carte afin de permettre une reconnexion après un chargement interrompu.
- Rejet des résultats de création des tuiles devenus obsolètes après un changement de configuration ou d’installation.
- Suppression du double montage dans le chemin de synchronisation stable et des réaffectations identiques de hass aux tuiles natives.

Correctif source de référence : 90424ff50efdc6363d9118aa0d54f769f315e25f.

## Livraison

Le workflow Release doit être exécuté depuis le tag v0.3.8 pointant sur un commit contenant cette préparation et le correctif. Il exécute npm ci, npm test et npm run build, copie le bundle reconstruit et les mentions de licences dans custom_components/flowio/frontend, puis crée flowio.zip et une release en brouillon.

Ne pas distribuer uniquement les fichiers TypeScript : le JavaScript livré doit être reconstruit depuis les sources corrigées.
